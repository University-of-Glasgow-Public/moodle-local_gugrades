This button menu provides functions for the Capture table. Some buttons may be disabled (greyed out) if they are not available in the current context.

  • Import Grades
    Import grades from Moodle activities or Gradebook for the currently selected grade item.
  • CSV Import
    Import grades directly from a CSV file into the currently selected item.
  • Add multiple
    Grades can be typed into the Capture Table directly.
  • Release/Unrelease grades
    Grades are released (or unreleased) for display in Student MyGrades.
  • Export capture Grades for the selected grade item are exported to a CSV file.
