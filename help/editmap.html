This page allows you to create a new (or edit an existing) conversion map. Maps are used to convert points grades to Scale values prior to final aggregation. Conversions can be applied to individual grade items on the Import Grades tab or can be applied to aggregated grade categories on the Aggregation tab. For example, you can aggregate a set of class quizzes into a single category grade which can then be converted.

For new maps a set of example values are entered into the table. As each School uses their own set of values you should modify these to suit your requirements.

Grade boundaries can be entered either as a percentage value or in points. If entering in points, the maximum grade should be given. NOTE: internally, conversion is always performed using percentages. This means that a conversion map can be applied to a grade item with a different maximum grade. In this case, a warning will be given, in case this was not what you intended. Points categories are always aggregated to a percentage.
